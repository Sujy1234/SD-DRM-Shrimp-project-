
# Shrimp SD-DRM analysis

This repository contains the R code and input data used to estimate infection risks associated with antibiotic-resistant *Vibrio parahaemolyticus* in imported shrimp using a simple death dose-response model (SD-DRM).

The analysis evaluates three exposure scenarios:

1. Raw shrimp consumption
2. Undercooked shrimp consumption
3. Hand-mediated cross-contamination

The model also examines how the fraction of resistant bacteria and the residual doxycycline concentration influence infection risk and the predicted treatability outcome.

## Main analysis files

- `Shrimp_SD-DRM.Rmd`  
  Main analysis file. It applies the SD-DRM to the simulated exposure doses, estimates event-level and annual infection risks, evaluates different resistant fractions and residual doxycycline concentrations, and generates summary tables and figures.

- `Sensitivity analysis.Rmd`  
  Conducts the sensitivity analysis using Spearman's rank correlation coefficients. The analysis is performed using all simulation iterations and separately using contaminated exposure events.

## Helper functions

- `model_functions.R`  
  Contains functions for the SD-DRM calculations, annual infection-risk simulation, and summary statistics.

- `Graph_funtion.R`  
  Contains the functions used to generate the figures.

## Input files

- `full_simulation_data_three_scenarios.csv`  
  Simulated exposure data for the raw shrimp, undercooked shrimp, and hand-mediated cross-contamination scenarios.

- `Emax and EC50.csv`  
  Paired bootstrap estimates of the doxycycline pharmacodynamic parameters $E_{\max}$ and $EC_{50}$.

## Output files

The analysis scripts generate two output folders: `results` and `images`.

### Results

The `results` folder contains the numerical outputs generated by the main SD-DRM analysis and the sensitivity analysis.

- `annual_risk_summary_varying_pMIC.csv`  
  Annual infection-risk summaries across residual doxycycline concentrations, with the resistant fraction fixed.

- `conditional_median_annual_risk_plot_data_varying_pMIC.csv`  
  Median and percentile estimates used to plot annual infection risk across residual doxycycline concentrations.

- `annual_risk_summary_varying_resistant_fraction.csv`  
  Annual infection-risk summaries across resistant fractions, with the residual doxycycline concentration fixed.

- `conditional_median_annual_risk_plot_data_varying_resistant_fraction.csv`  
  Median and percentile estimates used to plot annual infection risk across resistant fractions.

- `spearman_sensitivity_results.csv`  
  Spearman's rank correlation coefficients for each model input and exposure scenario, calculated using the complete simulation dataset and separately using contaminated exposure events.

### Images

The `images` folder contains the figures generated by the main SD-DRM analysis and the sensitivity analysis.

- `doxycycline_annual_dose_response_fixed_fr_varying_pMIC.png`  
  Annual dose-response curves at selected residual doxycycline concentrations, with the resistant fraction fixed.

- `doxycycline_mean_annual_risk_fixed_fr_varying_pMIC.png`  
  Mean annual infection risk across residual doxycycline concentrations, with the resistant fraction fixed.

- `doxycycline_conditional_median_annual_risk_fixed_fr_varying_pMIC.png`  
  Conditional median annual infection risk and Monte Carlo percentile intervals across residual doxycycline concentrations.

- `doxycycline_annual_dose_response_fixed_pMIC_varying_fr.png`  
  Annual dose-response curves at selected resistant fractions, with the residual doxycycline concentration fixed.

- `doxycycline_mean_annual_risk_fixed_pMIC_varying_fr.png`  
  Mean annual infection risk across resistant fractions, with the residual doxycycline concentration fixed.

- `doxycycline_conditional_median_annual_risk_fixed_pMIC_varying_fr.png`  
  Conditional median annual infection risk and Monte Carlo percentile intervals across resistant fractions.

- `spearman_sensitivity_two_panel.png`  
  Sensitivity-analysis figure comparing the analysis of the complete simulation dataset with the analysis restricted to contaminated exposure events.

## Additional files

- `SD-DRM output for sensitivity analysis.rds`  
  Intermediate simulation dataset generated by `Shrimp_SD-DRM.Rmd` and used as the input for `Sensitivity analysis.Rmd`. It contains the exposure-model inputs for the three shrimp scenarios, the sampled pharmacodynamic parameters $E_{\max}$ and $EC_{50}$, the resistant fraction, the residual doxycycline concentration, and the predicted event-level infection risks for raw shrimp consumption, undercooked shrimp consumption, and hand-mediated cross-contamination.

- `Shrimp_SD-DRM.html`  
  Rendered HTML output of the main SD-DRM analysis.

- `Sensitivity-analysis.html`  
  Rendered HTML output of the sensitivity analysis.

## Running the analysis

The analysis files should be run in the following order:

1. `Shrimp_SD-DRM.Rmd`
2. `Sensitivity analysis.Rmd`

The main analysis must be completed first because it generates the dataset used in the sensitivity analysis.
